# 🎯 HuntOpenHighlights

**HuntOpenHighlights** — автоматическая система записи лучших моментов (NVIDIA Highlights) для видеокарт **AMD Radeon**, **Intel Arc** и **NVIDIA** в играх с поддержкой NVIDIA Highlights (включая **Hunt: Showdown 1896**).

Система перехватывает игровые события в реальном времени (убийства, нокауты, смерти) и **автоматически сохраняет видеоклипы** через **OBS Studio (Replay Buffer)** с динамической длиной клипов и автоматическим именованием.

> **🛡️ 100% Anti-Cheat Safe:** Не модифицирует файлы игры, не внедряется в память процесса, использует исключительно официальные системные библиотеки с цифровыми подписями NVIDIA Corporation. Проверено и безопасно работает с **Easy Anti-Cheat (EAC)** в онлайн-матчах.

---

## ✨ Возможности

* 🎥 **100% программное сохранение через OBS WebSocket:** команда на запись летит по локальному сетевому сокету — **ноль нажатий клавиш в Windows**. Персонаж гарантированно не присядет (нет `Ctrl`), бег не собьётся (нет `Shift`), а зажатые клавиши не сломают запись.
* ✂️ **Динамическая длина клипов (Lossless Smart Trim):** мгновенно (за 0.09 сек, без перекодирования и без потери качества) отрезает лишнее пустое начало клипа до момента перестрелки:
  * Одиночный фраг $\rightarrow$ файл ровно **~25 секунд** (20 сек до выстрела + 5-7 сек после).
  * Серия фрагов (вайп сквада за 25 секунд) $\rightarrow$ файл ровно **~45 секунд**.
* 🏷️ **Умное именование файлов:** файлы сохраняются не со случайными именами, а с понятными тегами событий:
  * `Hunt_HUNTER_KILLED_Replay...mp4`
  * `Hunt_HUNTER_KILLED_x3_Replay...mp4` (при серии фрагов)
  * `Hunt_PLAYER_DOWNED_Replay...mp4`
* 🧠 **Склейка серий убийств (Smart Multi-Kill Coalescing):** если вы совершаете несколько убийств подряд, скрипт автоматически продлевает таймер и объединяет всю перестрелку в **один непрерывный эффектный клип**.
* ⚡ **Аппаратное кодирование видеокартой (AMD AMF):** запись идёт силами аппаратного чипа видеокарты (HEVC / AV1 / H.264) без нагрузки на процессор.
* 🎙️ **Раздельные аудиодорожки:** возможность в OBS писать звук игры, микрофон и Discord на разные аудиодорожки.
* 🤖 **Автозапуск буфера повтора:** скрипт сам автоматически активирует буфер повтора при запуске, руками кнопки в OBS нажимать не нужно.

## ⚡ Быстрый старт (Настройка за 1 минуту)

### Требования
* Windows 10 / 11 (64-bit)
* Видеокарта AMD Radeon, Intel Arc или NVIDIA
* Установленный [OBS Studio](https://obsproject.com/) (версия 28+)
* Установленный [Python 3.10+](https://www.python.org/downloads/) *(при установке обязательно поставьте галочку **"Add python.exe to PATH"**)*

---

### Шаг 1: Настройка OBS Studio (один раз)

1. **Включите WebSocket сервер:**
   * В верхнем меню OBS: **Инструменты** $\rightarrow$ **Настройки сервера WebSocket**.
   * Поставьте галочку: **«Включить сервер WebSocket»**.
   * Порт сервера: оставьте по умолчанию `4455`.
   * **Снимите галочку** с *«Включить аутентификацию»* (пароль не требуется, так как скрипт работает локально).
   * Нажмите **ОК**.
2. **Включите Буфер повтора:**
   * В OBS: **Файл** $\rightarrow$ **Настройки** $\rightarrow$ вкладка **Вывод**.
   * В блоке *«Запись»*:
     * **Путь к записи:** укажите папку для клипов (например, `E:\Videos\Clips`).
     * **Кодировщик видео:** выберите аппаратный чип видеокарты — **«Аппаратный (AMD, HEVC / AV1 / H.264)»** (или NVENC для Nvidia).
   * Поставьте галочку: **«Включить буфер повтора»** и задайте максимальную длительность (например, `60` секунд).
   * Нажмите **Применить** и **ОК**.
3. **Добавьте захват игры (если сцена пустая):**
   * Внизу в блоке *«Источники»*: нажмите **`+`** $\rightarrow$ **«Захват игры»** $\rightarrow$ «Захват отдельного окна» $\rightarrow$ *Hunt: Showdown 1896*.

---

### Шаг 2: Установка HuntOpenHighlights
1. Скачайте репозиторий (или клонируйте: `git clone https://github.com/Mlovo/HuntOpenHighlights.git`).
2. Нажмите правой кнопкой мыши по **`install.bat`** $\rightarrow$ **«Запуск от имени администратора»**.
   * *Скрипт автоматически создаст `C:\NvidiaShim`, скопирует подписанную библиотеку `MessageBus.dll`, зарегистрирует ключи в реестре Windows и установит зависимости.*

---

### Шаг 3: Запуск и игра
1. Запустите **OBS Studio** (можно свернуть в трей).
2. Запустите сервер:
   * **В окне консоли:** запустите **`run.bat`**
   * **В скрытом фоновом режиме:** запустите **`run_hidden.vbs`** (можно добавить в автозагрузку Windows: `Win + R` $\rightarrow$ `shell:startup`).
3. Запускайте **Hunt: Showdown 1896** и играйте! При каждом убийстве видеокарта сама сохранит и обрежет клип.

## ⚙️ Конфигурация (`config.json`)

Файл `config.json` находится в корне папки:

```json
{
    "obs": {
        "host": "localhost",
        "port": 4455,
        "password": "",
        "post_event_delay_sec": 7.0,
        "max_coalesce_sec": 60.0,
        "auto_start_replay_buffer": true,
        "auto_rename_clips": true,
        "smart_trim": true,
        "min_clip_sec": 20.0
    },
    "enabled_events": [
        "HUNTER_KILLED",
        "PLAYER_DOWNED"
    ],
    "log_to_desktop": false
}
```

### Описание параметров:
* **`obs.smart_trim`**: динамическая длительность клипов (`true`/`false`). Мгновенно отрезает лишнее пустое начало клипа до момента драки.
* **`obs.min_clip_sec`**: минимальная длительность клипа в секундах (по умолчанию 20 сек).
* **`obs.auto_rename_clips`**: автоматически переименовывать сохранённые клипы с понятными тегами (`Hunt_HUNTER_KILLED_...`, `Hunt_HUNTER_KILLED_x3_...` и т.д.).
* **`obs.post_event_delay_sec`**: задержка после события (по умолчанию 7 сек), чтобы в клип попал момент после фрага.
* **`obs.max_coalesce_sec`**: максимальное окно объединения серии фрагов в один непрерывный клип (по умолчанию 60 сек).
* **`obs.auto_start_replay_buffer`**: автоматически запускать буфер повтора в OBS при старте сервера.
* **`enabled_events`**: список отслеживаемых событий (убийства, нокауты/смерти).
* **`log_to_desktop`**: сохранять ли текстовый лог `HuntHighlights.log` на рабочий стол (`true`/`false`).

## 🎮 Как это работает под капотом

1. При запуске игры движок CryEngine связывается с локальным сервером через Named Pipe `\\.\pipe\NvMessageBusBroadcast`.
2. Игра автоматически разблокирует нативную кнопку **`[A] ЛУЧШИЕ МОМЕНТЫ NVIDIA`** на экране итогов матча.
3. Во время матча сервер перехватывает Protobuf-пакеты событий с таймингами (`startDelta: -20000ms`, `endDelta: 5000ms`).
4. Менеджер записи запускает умный таймер ожидания окончания боевого эпизода.
5. При серии фрагов таймер продлевается, объединяя все фраги перестрелки в один клип.
6. Сервер посылает сигнал сохранения в OBS по WebSocket без эмуляции клавиатуры.
7. После записи файл мгновенно переименовывается и бесшовно обрезается до точной длины боя.

## 🛡️ Безопасность и Easy Anti-Cheat

Обычные мок-библиотеки (`fake GfeSDK.dll`) приводят к ошибкам EAC `0xc000007b` и "Unknown file version", так как Easy Anti-Cheat проверяет цифровую подпись каждого файла в папке игры на уровне ядра.

**HuntOpenHighlights решает проблему иначе:**
* Папка игры **вообще не трогается** — все файлы игры остаются 100% оригинальными.
* Игра загружает подлинный `GfeSDK.dll`, который через стандартный реестр Windows обращается к официальному `C:\NvidiaShim\MessageBus.dll` (оба файла имеют подлинную цифровую подпись **NVIDIA Corporation**).
* Вся эмуляция происходит во внешнем независимом процессе через IPC (Inter-Process Communication).

## 🗺️ Структура проекта

```
HuntOpenHighlights/
├── bin/
│   └── MessageBus.dll          # Официальная подписанная 64-битная библиотека NVIDIA
├── proto/
│   ├── BusMessage.proto        # Схема Protobuf для системной шины NVIDIA
│   ├── sdk.proto               # Схема Protobuf для Highlights SDK
│   ├── BusMessage_pb2.py       # Скомпилированный модуль шины
│   └── sdk_pb2.py              # Скомпилированный модуль SDK
├── config.json                 # Пользовательские настройки (задержки, обрезка)
├── recorder.py                 # Менеджер записи (OBS WebSocket, авто-именование, Smart Trim)
├── server.py                   # Основной Named Pipe сервер
├── install.bat                 # Автоматический установщик (от Администратора)
├── run.bat                     # Запуск сервера в окне консоли
├── run_hidden.vbs              # Скрытый запуск в фоне
├── uninstall.bat               # Полное удаление настроек и файлов
├── requirements.txt            # Зависимости Python (pywin32, protobuf, obsws-python, imageio-ffmpeg)
└── README.md
```
