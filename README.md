# 🎯 HuntOpenHighlights

**HuntOpenHighlights** — автоматическая система записи лучших моментов (NVIDIA Highlights) для видеокарт **AMD Radeon** и **Intel Arc** в играх с поддержкой NVIDIA Highlights (включая **Hunt: Showdown 1896**).

Она перехватывает игровые события в реальном времени (убийства, нокауты, смерти) и **автоматически сохраняет видеоклипы** через **AMD Software: Adrenalin (ReLive Instant Replay)** или **OBS Studio (Replay Buffer)**.

> **100% Anti-Cheat Safe:** Не модифицирует файлы игры, не внедряется в память процесса, использует исключительно официальные системные библиотеки с цифровыми подписями NVIDIA Corporation. Проверено и безопасно работает с **Easy Anti-Cheat (EAC)** в онлайн-матчах.

---

## ✨ Возможности

* 🎥 **Автоматическая запись хайлайтов:** при нокауте противника (`HUNTER_KILLED`) или смерти (`PLAYER_DOWNED`) видеокарта сама сохраняет клип.
* 🧠 **Умная склейка серий убийств (Smart Multi-Kill Coalescing):** если вы совершаете несколько убийств подряд (например, вайп сквада за 15 секунд), скрипт не спамит дублирующимися клипами, а объединяет всю перестрелку в **один непрерывный эффектный клип**.
* ⚡ **AMD ReLive (Zero-Setup):** работает «из коробки» у любого владельца Radeon без необходимости ставить сторонний софт.
* 🎙️ **OBS Studio WebSocket:** поддержка раздельных звуковых дорожек (игра, микрофон, Discord) через буфер повтора OBS.
* ⚙️ **Гибкий `config.json`:** настройка горячих клавиш, таймингов задержки и фильтрации событий.

## ⚡ Быстрый старт (Установка за 1 минуту)

### Требования
* Windows 10 / 11 (64-bit)
* Видеокарта AMD Radeon (с включенной функцией «Мгновенный повтор» в Adrenalin) или OBS Studio
* Установленный [Python 3.10+](https://www.python.org/downloads/) *(при установке обязательно поставьте галочку **"Add python.exe to PATH"**)*

### Шаг 1: Настройка видеокарты (AMD Radeon)
1. Откройте **AMD Software: Adrenalin Edition** (`Alt + R`).
2. Перейдите в **Запись и трансляция** -> **Настройки** -> **Горячие клавиши**.
3. Включите **Мгновенный повтор** (Instant Replay) и задайте желаемую длительность (например, 60 секунд).
4. *(Рекомендуется для максимального комфорта):* Смените сочетание «Сохранить мгновенный повтор» на нейтральную клавишу, например **`F11`**, **`Scroll Lock`** или **`Ctrl + Alt + F10`**.
   > **Совет:** Стандартное сочетание `Ctrl + Shift + S` задействует клавиши приседания (`Ctrl`), спринта (`Shift`) и движения назад (`S`). Назначение нейтральной клавиши (например, `F11` или `Scroll Lock`) гарантирует, что в разгар перестрелки персонаж не дернется, а зажатый бег (`W`) не собьет сохранение! HuntOpenHighlights автоматически распознает любую клавишу из настроек драйвера.

### Шаг 2: Установка HuntOpenHighlights
1. Скачайте репозиторий (или клонируйте: `git clone https://github.com/Mlovo/HuntOpenHighlights.git`).
2. Нажмите правой кнопкой мыши по **`install.bat`** -> **«Запуск от имени администратора»**.
   * *Скрипт автоматически создаст `C:\NvidiaShim`, скопирует подписанную библиотеку `MessageBus.dll`, зарегистрирует ключи в реестре Windows и установит зависимости.*

### Шаг 3: Запуск
* **В окне консоли:** Запустите **`run.bat`**
* **В скрытом фоновом режиме:** Запустите **`run_hidden.vbs`** (или добавьте его ярлык в автозагрузку Windows: `Win + R` -> `shell:startup`).

После этого запускайте **Hunt: Showdown 1896** и играйте! При каждом убийстве видеокарта сама сохранит клип.

## ⚙️ Конфигурация (`config.json`)

При первом запуске автоматически создается файл настроек `config.json`:

```json
{
    "mode": "relive",
    "relive": {
        "hotkey": "auto",
        "post_event_delay_sec": 7.0,
        "max_coalesce_sec": 60.0
    },
    "obs": {
        "host": "localhost",
        "port": 4455,
        "password": "",
        "post_event_delay_sec": 7.0,
        "max_coalesce_sec": 60.0,
        "auto_start_replay_buffer": true
    },
    "enabled_events": [
        "HUNTER_KILLED",
        "PLAYER_DOWNED"
    ],
    "log_to_desktop": false
}
```

* **`relive.hotkey`**: 
  * `"auto"` — автоматически считывает текущую горячую клавишу повтора прямо из реестра AMD Adrenalin (рекомендуется).
  * Или вручную список: например `["f11"]`, `["scroll_lock"]`, `["ctrl", "alt", "f10"]`.

* **`mode`**: 
  * `"relive"` — сохранение через AMD Radeon Instant Replay (по умолчанию).
  * `"obs"` — сохранение через OBS Studio Replay Buffer (WebSocket).
  * `"disabled"` — режим только мониторинга/логов.
* **`post_event_delay_sec`**: сколько секунд ждать после события (чтобы в клип попал момент после фрага).
* **`max_coalesce_sec`**: максимальное окно объединения серии фрагов в один клип (по умолчанию 60 сек).
* **`log_to_desktop`**: включить сохранение текстового лога `HuntHighlights.log` на рабочий стол.

## 🎮 Как это работает под капотом

1. При запуске игры движок CryEngine связывается с сервером через Named Pipe `\\.\pipe\NvMessageBusBroadcast`.
2. Игра автоматически разблокирует нативную кнопку **`[A] ЛУЧШИЕ МОМЕНТЫ NVIDIA`** на экране итогов матча.
3. Во время матча сервер ловит события с точными таймингами (`startDelta: -20000ms`, `endDelta: 5000ms`).
4. Менеджер записи запускает умный таймер ожидания окончания боевого эпизода.
5. При серии фрагов таймер автоматически продлевается.
6. Сервер посылает аппаратно-согласованный сигнал на сохранение буфера повтора прямо в драйвер видеокарты или OBS.

## 🛡️ Безопасность и Easy Anti-Cheat

Обычные мок-библиотеки (`fake GfeSDK.dll`) приводят к ошибкам EAC `0xc000007b` и "Unknown file version", так как Easy Anti-Cheat проверяет цифровую подпись каждого файла в папке игры на уровне ядра.

**HuntOpenHighlights решает проблему иначе:**
* Папка игры **вообще не трогается** — все файлы игры остаются 100% оригинальными.
* Игра загружает подлинный `GfeSDK.dll`, который через стандартный реестр Windows обращается к официальному `C:\NvidiaShim\MessageBus.dll` (оба файла имеют подлинную цифровую подпись **NVIDIA Corporation**).
* Вся эмуляция происходит во внешнем независимом процессе через IPC (Inter-Process Communication).

## 🗺️ Структура проекта

```
HuntOpenHighlights/
├── bin/
│   └── MessageBus.dll          # Официальная подписанная 64-битная библиотека NVIDIA
├── proto/
│   ├── BusMessage.proto        # Схема Protobuf для системной шины NVIDIA
│   ├── sdk.proto               # Схема Protobuf для Highlights SDK
│   ├── BusMessage_pb2.py       # Скомпилированный модуль шины
│   └── sdk_pb2.py              # Скомпилированный модуль SDK
├── config.json                 # Пользовательские настройки (создается автоматически)
├── recorder.py                 # Менеджер записи (ReLive, OBS, умная склейка)
├── server.py                   # Основной Named Pipe сервер
├── install.bat                 # Автоматический установщик (от Администратора)
├── run.bat                     # Запуск сервера в окне консоли
├── run_hidden.vbs              # Скрытый запуск в фоне
├── uninstall.bat               # Полное удаление настроек и файлов
├── requirements.txt            # Зависимости Python (pywin32, protobuf, obsws-python)
└── README.md
```
