# 🎯 HuntOpenHighlights

**HuntOpenHighlights** — автоматическая система записи лучших моментов (NVIDIA Highlights) для видеокарт **AMD Radeon** и **Intel Arc** в играх с поддержкой NVIDIA Highlights (включая **Hunt: Showdown 1896**).

Система перехватывает игровые события в реальном времени (убийства, нокауты, смерти) и **автоматически сохраняет видеоклипы** через **OBS Studio (Replay Buffer)** или **AMD Software: Adrenalin (ReLive Instant Replay)**.

> **🛡️ 100% Anti-Cheat Safe:** Не модифицирует файлы игры, не внедряется в память процесса, использует исключительно официальные системные библиотеки с цифровыми подписями NVIDIA Corporation. Проверено и безопасно работает с **Easy Anti-Cheat (EAC)** в онлайн-матчах.

---

## ✨ Возможности

* 🎥 **Автоматическая запись хайлайтов:** при нокауте противника (`HUNTER_KILLED`) или смерти (`PLAYER_DOWNED`) видеокарта сама сохраняет клип.
* 🧠 **Умная склейка серий убийств (Smart Multi-Kill Coalescing):** если вы совершаете несколько убийств подряд (например, вайп сквада за 15 секунд), скрипт не спамит дублирующимися клипами, а объединяет всю перестрелку в **один непрерывный эффектный клип**.
* 🌐 **OBS Studio WebSocket (Рекомендуется):** 100% программное сохранение через сетевой сокет — **ноль нажатий клавиш в Windows**, раздельные аудиодорожки (микрофон, игра, Discord), автозапуск буфера повтора.
* ⚡ **AMD ReLive (Zero-Setup):** прямое сохранение через драйвер AMD Radeon без необходимости запускать сторонний софт, с автоопределением горячих клавиш из реестра Windows.
* ⚙️ **Гибкий `config.json`:** тонкая настройка задержек, горячих клавиш и фильтрации игровых событий.

## ⚡ Быстрый старт (Установка за 1 минуту)

### Требования
* Windows 10 / 11 (64-bit)
* Видеокарта AMD Radeon или Intel Arc
* Установленный [Python 3.10+](https://www.python.org/downloads/) *(при установке обязательно поставьте галочку **"Add python.exe to PATH"**)*

---

### Шаг 1: Выберите и настройте режим записи

#### Вариант А: OBS Studio (Рекомендуется — 100% без нажатия кнопок)
*Настройка занимает ровно 1 минуту:*

1. **Включите WebSocket сервер в OBS:**
   * В верхнем меню OBS: **Инструменты** $\rightarrow$ **Настройки сервера WebSocket**.
   * Поставьте галочку: **«Включить сервер WebSocket»**.
   * Порт сервера: оставьте по умолчанию `4455`.
   * **Снимите галочку** с *«Включить аутентификацию»* (пароль не требуется, связь идёт локально).
   * Нажмите **ОК**.
2. **Включите Буфер повтора:**
   * В OBS: **Файл** $\rightarrow$ **Настройки** $\rightarrow$ вкладка **Вывод**.
   * В блоке *«Запись»*:
     * **Путь к записи:** укажите папку для клипов (например, `E:\Videos\Clips`).
     * **Кодировщик видео:** выберите аппаратный чип AMD — **«Аппаратный (AMD, HEVC / AV1 / H.264)»**.
   * Поставьте галочку: **«Включить буфер повтора»** и задайте длительность (например, `60` секунд).
   * Нажмите **Применить** и **ОК**.
3. **Добавьте захват игры (если сцена пустая):**
   * Внизу в блоке *«Источники»*: нажмите **`+`** $\rightarrow$ **«Захват игры»** $\rightarrow$ «Захват отдельного окна» $\rightarrow$ *Hunt: Showdown 1896*.
4. В файле [`config.json`](config.json) установите:
   ```json
   "mode": "obs"
   ```
   *(При запуске наш скрипт сам автоматически активирует буфер повтора в OBS, руками кнопку нажимать не нужно).*

---

#### Вариант Б: AMD Software Adrenalin (ReLive)
*Работает напрямую через драйвер AMD Radeon:*

1. Откройте **AMD Software: Adrenalin Edition** (`Alt + R`).
2. Перейдите в **Запись и трансляция** $\rightarrow$ **Настройки** $\rightarrow$ **Горячие клавиши**.
3. Включите **Мгновенный повтор** (Instant Replay) и задайте длительность (например, 60 секунд).
4. Убедитесь, что настроена клавиша «Сохранить мгновенный повтор».  
   > 💡 **Совет:** По умолчанию AMD использует `Ctrl + Shift + S`. В файле `config.json` включено автоопределение (`"hotkey": "auto"`), скрипт сам прочитает клавишу из реестра Windows.

---

### Шаг 2: Установка HuntOpenHighlights
1. Скачайте репозиторий (или клонируйте: `git clone https://github.com/Mlovo/HuntOpenHighlights.git`).
2. Нажмите правой кнопкой мыши по **`install.bat`** $\rightarrow$ **«Запуск от имени администратора»**.
   * *Скрипт автоматически создаст `C:\NvidiaShim`, скопирует подписанную библиотеку `MessageBus.dll`, зарегистрирует ключи в реестре Windows и установит зависимости.*

---

### Шаг 3: Запуск
* **В окне консоли:** Запустите **`run.bat`**
* **В скрытом фоновом режиме:** Запустите **`run_hidden.vbs`** (можно добавить в автозагрузку Windows: `Win + R` $\rightarrow$ `shell:startup`).

После этого запускайте **Hunt: Showdown 1896** и играйте! При каждом убийстве видеокарта сама сохранит клип.

## ⚙️ Конфигурация (`config.json`)

Файл `config.json` находится в корне папки:

```json
{
    "mode": "obs",
    "relive": {
        "hotkey": "auto",
        "post_event_delay_sec": 7.0,
        "max_coalesce_sec": 60.0
    },
    "obs": {
        "host": "localhost",
        "port": 4455,
        "password": "",
        "post_event_delay_sec": 7.0,
        "max_coalesce_sec": 60.0,
        "auto_start_replay_buffer": true,
        "auto_rename_clips": true,
        "smart_trim": true,
        "min_clip_sec": 20.0
    },
    "enabled_events": [
        "HUNTER_KILLED",
        "PLAYER_DOWNED"
    ],
    "log_to_desktop": false
}
```

### Параметры:
* **`mode`**: 
  * `"obs"` — сохранение через OBS Studio Replay Buffer (WebSocket API, 0 нажатий клавиш).
  * `"relive"` — сохранение через AMD Radeon Instant Replay.
  * `"disabled"` — режим только мониторинга событий без записи.
* **`obs.smart_trim`**: динамическая длительность клипов! Мгновенно (за 0.1 сек, без перекодирования) отрезает лишнее пустое начало клипа, оставляя только саму перестрелку (~25 сек на одиночный фраг, ~40-50 сек на серию фрагов).
* **`obs.min_clip_sec`**: минимальная длительность клипа в секундах (по умолчанию 20 сек).
* **`obs.auto_rename_clips`**: автоматически переименовывать сохранённые клипы с понятными тегами (`Hunt_HUNTER_KILLED_...`, `Hunt_HUNTER_KILLED_x3_...` и т.д.).
* **`relive.hotkey`**: 
  * `"auto"` — автоматическое считывание текущей горячей клавиши прямо из реестра AMD Adrenalin.
  * Или вручную список: например `["ctrl", "alt", "f10"]`, `["ctrl", "shift", "s"]`.
* **`post_event_delay_sec`**: задержка после события (по умолчанию 7 сек), чтобы в клип попал момент после фрага.
* **`max_coalesce_sec`**: максимальное окно объединения серии фрагов в один непрерывный клип (по умолчанию 60 сек).
* **`obs.auto_start_replay_buffer`**: автоматически запускать буфер повтора в OBS при старте.
* **`log_to_desktop`**: сохранять ли текстовый лог `HuntHighlights.log` на рабочий стол (`true`/`false`).

## 🎮 Как это работает под капотом

1. При запуске игры движок CryEngine связывается с локальным сервером через Named Pipe `\\.\pipe\NvMessageBusBroadcast`.
2. Игра автоматически разблокирует нативную кнопку **`[A] ЛУЧШИЕ МОМЕНТЫ NVIDIA`** на экране итогов матча.
3. Во время матча сервер перехватывает Protobuf-пакеты событий с таймингами (`startDelta: -20000ms`, `endDelta: 5000ms`).
4. Менеджер записи запускает умный таймер ожидания окончания боевого эпизода.
5. При серии фрагов таймер продлевается, объединяя все фраги перестрелки в один клип.
6. Сервер посылает сигнал сохранения в OBS по WebSocket или драйверу AMD ReLive.

## 🛡️ Безопасность и Easy Anti-Cheat

Обычные мок-библиотеки (`fake GfeSDK.dll`) приводят к ошибкам EAC `0xc000007b` и "Unknown file version", так как Easy Anti-Cheat проверяет цифровую подпись каждого файла в папке игры на уровне ядра.

**HuntOpenHighlights решает проблему иначе:**
* Папка игры **вообще не трогается** — все файлы игры остаются 100% оригинальными.
* Игра загружает подлинный `GfeSDK.dll`, который через стандартный реестр Windows обращается к официальному `C:\NvidiaShim\MessageBus.dll` (оба файла имеют подлинную цифровую подпись **NVIDIA Corporation**).
* Вся эмуляция происходит во внешнем независимом процессе через IPC (Inter-Process Communication).
